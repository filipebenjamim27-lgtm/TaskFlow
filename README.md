# TaskFlow
TaskFlow  TaskFlow is a task management system developed in Python, designed to make it easier to create, organize, update, and delete tasks through a CRUD-based system.  The project aims to provide a simple and intuitive solution for managing checklists, allowing users to keep track of their tasks and stay organized.

# Tools used
front -> HTML5, CSS E JS
Back -> Python
FrameWork -> flask
BDS -> SQLite
